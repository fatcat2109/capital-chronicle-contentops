# `video/` — Tier-2 Renderer Scope

Master currently has no accepted renderer implementation in this tree. The Remotion files on
`task/tier2-b-remotion-multimodal-bakeoff-v1` are rejected product work and reference only.

When a fresh authorized V2 task creates renderer code here:

- consume the renderer-neutral `VideoProgram`; do not make React props/FFmpeg commands product
  authority;
- preserve native 16:9 long-form and independently directed 9:16 short-form layouts;
- support scene/chapter caching, proxy renders, selective rerender, and deterministic hashes;
- keep visuals claim/evidence/rights bound and synthetic assets clearly illustrative;
- add no provider credential, upload, browser, publication, state-store, or newsroom authority;
- use premium institutional typography/motion, not the rejected Tier2-B visual implementation;
- keep generated/vendor output (`node_modules`, renders, caches, runtime media) outside Git.

Tests should cover program-schema consumption, responsive layout, cache invalidation, and render
metadata. Final aesthetic acceptance remains Jim/ChatGPT visual review, not renderer self-score.
