# ContentOps V5 Cockpit Screenshot QA Convention

This convention ensures that visual evidence captured for release review is consistent, clean, and free of browser/OS chrome noise.

## Viewport Standards

All screenshots must be captured under the following viewport dimensions:
1. **Desktop Standard**: 1440x900
2. **Desktop Alternate (if needed)**: 1280x800
3. **Mobile Drawer Standard**: 480x800

## Clean Screen Capture Rules

1. **App Viewport Only**: Crop the screenshot strictly to the HTML document boundaries. Do not include browser tabs, URL address bars, bookmark bars, developer tools, OS windows, or desktop wallpaper.
2. **Theme Consistency**: Other rooms use the configured theme (light/dark-evidence), while the *Evidence Vault* and *Operator Runbook* are always captured in dark-evidence mode.
3. **No Overlays**: Close any active browser popups or overlay notifications before capturing, unless specifically capturing modal state.
