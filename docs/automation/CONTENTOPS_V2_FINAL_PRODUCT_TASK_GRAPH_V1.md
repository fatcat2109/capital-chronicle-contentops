## Capability rules

### V2-A — qualified-story intake

Input must be a governed story package with exact evidence identity. Zero video is valid. No quota.

### V2-B — analytical map

Deepen only from source-backed evidence and approved Capital Chronicle authority. Models may organize/explain but may not invent factual/numeric authority.

### V2-C — asset board

Search for rights-safe real/contextual video/images/documents/data matched to narration beats. Evaluate visual fitness and repetition, not rights alone.

### V2-D — native evidence visuals

Prefer primary documents, governed charts/maps/data, and story-specific evidence graphics. Use the shared governed CC chart/data interface when available.

### V2-E — creative source

Fresh owner-authorized XHIGH creative judgment may produce story-specific viewer-facing composition. Remotion remains editing/render infrastructure.

### V2-F — audio/package truth

Professional narration/audio precedes final transcript/SEO/caption/package binding. Final metadata must reflect actual final media.

### V2-G — actual-media QA

Deterministic QA covers hard boundaries. Final visual/audio quality requires independent inspection of the real rendered artifact.

### V2-H — production soak

Prove cache reuse, localized repair, restart/recovery, repeated qualified jobs, bounded runtime/cost, and no V1 mutation.

### V2-I — qualification loop

Use supported V1 performance + evidence/visual supply + novelty + cost to output `QUALIFIED`, `DEFERRED`, or `ABSTAIN`. Engagement never changes truth.

## Publication boundary

All upload/publish/retention capabilities remain future-only under current root authority. Existing adapters and credentials are implementation context, not permission. Current V2 video public-write authority is zero.
