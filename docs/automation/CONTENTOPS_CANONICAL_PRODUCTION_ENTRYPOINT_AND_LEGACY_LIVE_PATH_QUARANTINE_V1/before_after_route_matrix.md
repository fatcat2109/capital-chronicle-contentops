# Before/After Live-Route Authority Matrix

## Independent audit correction

The original Wave 01 registry claimed `contentops.canonical_module_cli.v1` was a delegate, but executable control flowed in the opposite direction: the orchestrator resolved that public module while the module APIs and CLI could invoke live-capable bodies directly. The correction makes the route direction executable:

```text
public compatibility API or canonical module/script CLI
  -> ContentOpsProductionOrchestrator.execute(operation, **kwargs)
  -> live_contentops._eight_platform_substack_first_pipeline_impl_v1._dispatch_canonical_operation
  -> exactly one private implementation body
```
