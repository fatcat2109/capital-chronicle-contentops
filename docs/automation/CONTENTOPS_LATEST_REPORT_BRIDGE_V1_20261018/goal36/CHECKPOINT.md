## Delivered owner journey

The existing Desk now leads with **Stories to follow**. Opening a native story shows
its current dated view, reader question, competing explanation, factual source delta,
separate authored interpretation comparison, next observation and prior/current accepted
versions. A later KEEP assessment no longer hides the fact delta that created the
revision. Model-routing details and exact technical identities are under disclosures.

Version disclosures expose the immutable full canonical copy/SEO, exact source dates,
source/analysis/check ages, media or explicit gap, eight destination packages and actual
revision-review/prepared/publication states. A source check is not a new publication
date or independent confirmation. Date precision already in accepted evidence stays
unchanged; normalized historical clocks are not upgraded to verified precision.
Missing parent versions show an explicit lineage gap, never a guessed issuer/title join.

The existing owner entry is:

`python scripts/run_native_desktop_editorial.py follow-up --source-review-id <exact-current-review-id>`

USE_UNCHANGED and STALE_OR_SOURCE_GAP return without an editorial operation/model call.
A material review reopens its accepted child, resumes one frozen pending binding, or
allocates one stable existing newsroom operation when warranted. Omitted custom wording
survives interruption. A second operation cannot duplicate an accepted follow-up, and
superseded reviews fail closed. New follow-up pools exclude unrelated candidates.
Publisher corrections preserve the existing correction decision, and re-reviewing a
follow-up retains its original chain. Existing 32/3/6 budgets, native role assignments,
source/rights/numeric boundaries, compiler and sole coordinator remain authoritative.

## Pure completed-story/revision read contract for Desks

No new API, queue, store or status owner. Existing `report_workspace_projection(...)`
returns additive `maintained_stories[]` beside `native_edition` under the existing
`contentops.cc_report_editorial_workspace.v1` schema. Existing
`native_story_projection(edition, rows, observed_at_utc=...)` is a pure completed-input
projection: no filesystem/network/model/store writes. Pass an observation clock for
deterministic ages. Select by exact `story_identity` plus `current_article_identity`;
select a version by `versions[].article_identity`.

| Purpose | Fields |
| --- | --- |
| Story/current view | story_identity, current_article_identity, current_view, reader_question, countercase, state |
| Ancestry | versions[], declared/resolved prior identity, lineage_gap; no inferred issuer/title ancestry |
| Factual revision | change.decision/summary/source_changes: the source review that created the revision |
| Authored interpretation | prior_interpretation, current_interpretation, interpretation_changed; not new market facts |
| Later source check | latest_assessment with decision, cutoff/check clocks and named gaps; does not erase the revision delta |
| Next observation | next_observation and exact accepted derivative origin; missing stays unavailable |
| Dates/age | version analysis_as_of_utc, accepted_at_utc, analysis_age_seconds, source_dates[], last_source_check_utc |
| Accepted copy/support | version article, evidence, source_checks; original public-safe source/claim lineage |
| Packages and publication | version previews, media_assets, review, prepared_state, publication |

Display state maps existing semantics: USE_UNCHANGED→KEEP, STALE_OR_SOURCE_GAP→HOLD,
MATERIAL_FOLLOW_UP→UPDATE; correction/withdrawal retains its existing name. No comparison
shows NEW without claiming present confirmation. This is no new persisted lifecycle or
automatic expiry. Publication remains separately owned. Main report cutoffs are labelled
as report clocks, not source-publication clocks. Missing ages stay unknown; pending URLs
remain pending. Static ages apply at the readback clock, not continuously in the browser.

Read the existing HTML/JSON generated by `python scripts/run_native_desktop_editorial.py desk`.
No Desks code/thread was changed or contacted. Original accepted language is preserved.
