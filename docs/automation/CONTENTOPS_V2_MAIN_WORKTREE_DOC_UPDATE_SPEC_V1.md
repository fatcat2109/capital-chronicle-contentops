## 4. Transcript authority

Every accepted video should converge on a hash-bound canonical spoken transcript and a final-audio-aligned transcript/caption state.

Blocking defects include:

- entity/name mismatch;
- number/date/currency/unit mismatch;
- negation or modality reversal;
- observation/forecast drift;
- speaker/clip boundary mismatch;
- corrupted/missing/duplicated segments;
- caption timing mismatch.

Draft narration and unreviewed platform auto-captions are not transcript authority.
