## 2. Optional Context Sources (Only When Relevant)
The following files should be added temporarily and removed once their scoped tasks are finished:
* **Ingestion Notes**: Ingestion or database mapping notes should only be uploaded for ingestion/artifact connector tasks.
* **Visual/UI Guides**: Wireframe coordinates or visual design criteria should only be uploaded for visual layout and user interface tasks.
* **Evidence Packets**: Concrete evidence packets should only remain uploaded during their specific audit and verification cycles.
