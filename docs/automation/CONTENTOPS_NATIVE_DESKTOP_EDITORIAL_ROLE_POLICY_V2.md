## Data and execution sequence

Unchanged bulk X CDP ingestion
-> deterministic exact dedupe and governed intake
-> bounded, resumable Luna/Terra-MAX semantic filtering
-> Sol-Light content selection and data/evidence planning
-> existing code/tools retrieve, normalize, compute and validate lawful evidence
-> immutable compact evidence, claim, prior-story and editorial-style packet
-> Sol-MAX writing and, when useful, one bounded same-writer repair
-> existing deterministic source/claim/epistemic validation
-> existing article/native eight-channel compiler and revision-bound review
-> sole existing DurablePublicationCoordinator and strict readback/reconciliation.

Do not truncate the unprocessed ingestion backlog to the latest 32 and call it fully filtered.
Use existing cursor/outbox/checkpoint owners, bounded batches, exact input/output hashes and
seen/kept/rejected/deferred counts. Preserve original records and correction/update identity.
An interruption resumes completed stages; unchanged inputs do not rerun model work. A semantic
filter output remains a relevance judgment, not an independently established news fact.

The downstream content-selection candidate pool remains bounded at <=32, with the existing
<=3 admitted candidates and shared <=6 source-request budget. These downstream limits do not
claim the entire upstream backlog was evaluated. Raw X history must not flood the MAX writer.

Data preparation means selecting the question and executing existing approved resolution tools.
Code retains numeric extraction, parsing, dedupe, unit/currency/time transformations and calculations.
Existing source/PIT/rights/freshness and Main/Core numeric authority remain. ContentOps may use
only the properly admitted public or otherwise permitted consumer surfaces; no database backfill,
private Main/company/account leakage or duplicate data owner is introduced.

Preserve evidence-led financial journalism: a strong defensible thesis, material context and
mechanism, supported skeptical/critical/contrarian analysis, a serious countercase, uncertainty,
reader utility and clear prose. Voice references are standards and characteristics, not copied
proprietary text. Dry humor is optional and subject to the existing story-class policy.
No artificial word targets, generic boilerplate, fabricated outrage or invented certainty.

Canonical headline, search title, social hook, dek, description, slug, reader questions,
internal-link suggestions and supported structured data must describe the same evidenced
proposition. Natural search intent and readability come before keyword repetition.
First-screen clarity, factual attribution and the difference between reporting, confirmation,
CC analysis and conditional scenarios survive every derivative.
SEO hygiene is separate from observed search/audience results; a local score proves no ranking.
