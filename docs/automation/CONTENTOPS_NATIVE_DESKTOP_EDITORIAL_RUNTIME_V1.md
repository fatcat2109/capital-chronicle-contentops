# Native Codex Desktop editorial runtime V1

Authority: Jim's 2026-10-20 direction. Target owner: `NATIVE_CODEX_DESKTOP`.
Model: `gpt-6.1-sol`; effort: `low` (Light); speed: standard. Builder model stays unchanged.
Named difficult contradictions/high-harm corrections may warrant medium/high; never above HIGH.
This engineering slice has zero activation, deployment or public-write authority.

## One supported opportunity

Native App scheduled task or explicit owner-manual conversation
→ existing window/production-day/slot binding
→ MainReportFeed, current <=32 candidates, reviewed retained research and canonical memory
→ native Desktop selection/reasoning
→ shared <=6 deterministic source requests, primary + <=2 useful fallbacks
→ native Desktop writing
→ existing source/claim/epistemic validation and <=1 useful repair
→ article and exactly eight platform packages
→ revision-bound review and existing sole DurablePublicationCoordinator handoff.

`scripts/run_native_desktop_editorial.py` advances this same lifecycle. Pending JSON is a
tool request for the conversation currently running, not an invented Python-to-chat API.
The conversation authors and submits its actual result and continues in the same turn.
Subagents are optional only for an independent need; no routine selector/writer/reviewer fleet.
No Gemini, 9Router, SDK, App-Server, headless or paid API model fallback exists in this path.

The existing outbox holds frozen input, request, response, source checkpoints and final result.
Requests/responses are immutable and hash-bound. Leases/fencing remain in the existing store.
Successful stages replay after interruption; opaque started source attempts fail closed.
Scheduled resume returns an already qualified slot at its review/handoff boundary before
allocating the next slot. A final article alone never means review/handoff completed.
UNKNOWN/ambiguous dispatch recovery precedes fresh editorial work. No blind retry.
Media with unchanged source/rights/review/hash is reused; an earlier article is never a source.

Telemetry records observable native invocation identity/model/effort and semantic responses.
Unexposed token totals, API call counts and dollar cost are null, never invented zero or tariff.
Compatibility `simple_*` artifact filenames and accepted deterministic functions are reused;
their names do not establish a Gemini model invocation. Historical Simple proofs stay intact.
