## 6. Legacy EIA Hormuz map decision

The current EIA Hormuz raster is not acceptable as a professional final-media presentation asset.

Problems include:

- baked-in typography;
- irrelevant pipeline labels;
- excessive map clutter;
- uncontrolled hierarchy;
- native label competition with Capital Chronicle overlays;
- weak aspect-ratio flexibility;
- report-screenshot aesthetic rather than premium editorial map craft.

Decision:

**Retire the legacy EIA Hormuz raster from professional-final presentation.**

It may remain as factual/reference evidence.

If the story requires Hormuz geography again, use a Capital Chronicle native map treatment built from geographically truthful/rights-safe data or a clean satellite/geographic base with controlled vector overlays and Capital Chronicle typography.

## 7. Asset-first future pipeline

Canonical quality-hardening order:

`Governed Story -> Institutional Analytical Map -> Evidence Expansion -> Visual Entity/Asset Needs -> Fresh Rights-Safe Asset Discovery -> Candidate Asset Board -> ASSET_VISUAL_FIT Gate -> Codex Asset Selection -> Storyboard -> Codex-Authored Remotion Source -> Proxy -> Review/Repair -> Final`

Do not default to:

`Story -> pick old local asset -> compose around it`.

## 8. Candidate Asset Board

For each major beat, provide multiple visual candidates where practical before the final storyboard.

Each candidate should include:

- source;
- rights status;
- resolution;
- orientation;
- focal subject;
- crop viability;
- embedded/baked-in text;
- semantic match;
- visual family;
- prior-use count/recent-video use;
- documentary versus illustrative classification;
- attribution requirements.

The board should be visually inspectable through thumbnails/contact sheets or an equivalent artifact.

Codex should select from this universe as an editorial director, not blindly reuse the first available local asset.

## 9. ASSET_VISUAL_FIT gate

Rights-safe does not mean visually acceptable.

A professional candidate asset must also pass visual-fitness checks such as:

- semantic match;
- sufficient resolution;
- clear focal subject;
- controlled clutter;
- limited baked-in text;
- crop flexibility;
- visual tone/lighting;
- orientation fitness;
- uniqueness versus recent scenes/videos;
- professional editorial feel.

Reject an asset before storyboard if it is rights-safe but visually poor.

The legacy EIA Hormuz raster is the canonical negative example for this gate.

## 10. Asset diversity must be semantic, not only file-count based

The proof reported 11 governed assets and low maximum single-asset time concentration. That is useful but insufficient.

A viewer can still experience visual repetition when multiple different files belong to the same family:

- tanker/tanker/tanker;
- refinery/refinery;
- storage/storage;
- repeated oil infrastructure.

Future metrics must include:

- exact-file reuse;
- visual-family concentration;
- semantic-purpose reuse;
- consecutive reuse;
- recent-video reuse;
- cumulative screen time by visual family.

Actual rendered dependencies, not only creative-plan asset IDs, are the source of truth.

## 11. Native map compiler direction

Build only the reusable capability needed by real stories, not a giant GIS platform.

Desired result:

- geographically truthful outline/base;
- Capital Chronicle-controlled typography;
- only story-relevant labels;
- route/flow overlays with semantic meaning;
- native 9:16 and 16:9 variants;
- optional rights-safe satellite/documentary base;
- no irrelevant baked-in report labels.

For Hormuz specifically, a strong pattern is:

`satellite/geographic context -> controlled zoom -> clean Strait outline/route overlay -> tanker cutaway`.

The map is an explanatory visual, not a screenshot of somebody else's report layout.

## 12. Data visualization upgrade

The current `$85 -> $74 -> $65` chart is clear, but it remains a very simple three-point path.

Where source data supports it, future charts should consider:

- a short observed-history segment;
- explicit observed/forecast divider;
- real date anchors;
- direct labels;
- a relevant comparison/range;
- highlighted delta or breakpoint;
- native 9:16/16:9 composition.

Do not increase complexity unless it adds explanatory value.

The goal is to look and function like institutional data visualization rather than a decorative number line.

## 13. Evidence Expansion and institutional depth

Institutional depth should come from stronger evidence, not more words on screen.

After selecting two to four high-value second-order channels, attempt to bind each important on-screen channel to an additional primary/strong evidence anchor or hard number.

Examples, depending on the story/domain:

- inventory levels/change;
- shipping flow;
- refinery utilization;
- freight/insurance costs;
- futures curve structure;
- fiscal breakeven or producer cash-flow exposure;
- importer current-account exposure;
- labor/inflation components;
- rates/FX transmission.

If strong authority is not available, keep the implication qualitative in narration or omit it. Do not manufacture institutional-looking precision.

## 14. Micro-beat editing

Several current midform scenes last roughly 8–12 seconds while the visual state changes only modestly.

The next ceiling requires micro-beat planning inside scenes.

Starting heuristic:

- meaningful visual state change approximately every 2–4 seconds;
- longer holds allowed where documents/data need actual reading time;
- visual change follows information change, not a generic motion quota.

Example physical mechanism progression:

`tanker -> unload -> terminal/pipe -> production -> storage -> resolved mechanism`.

A ten-second analytical idea can contain several meaningful visual states without becoming frantic.

## 15. Material rhythm

Capital Chronicle should remain recognizable through consistent design tokens, typography and evidence discipline, but the video should not become visually monotonous.

Use controlled material variation such as:

- full-bleed documentary media;
- clean native map;
- bright primary-source document;
- dark data view;
- micro-montage;
- minimal thesis frame;
- chart scene;
- physical mechanism sequence.

Brand consistency does not require every frame to be the same navy card.

## 16. Severe visual/taste gate

The current internal QA is effective at deterministic defects such as collisions, empty conditions and invalid provenance. It is still too permissive on taste.

Before expensive motion, explicitly ask:

> Would an institutional media editor approve this exact asset and composition for publication?

Evaluate:

- asset quality;
- visual novelty;
- visual richness;
- professional taste;
- embedded-text clutter;
- crop quality;
- hierarchy;
- semantic clarity;
- visual-family repetition;
- template feel;
- whether the scene looks like premium Capital Chronicle media.

If the answer is not a clear yes, revise before full motion.

Worker/critic self-PASS remains evidence, not owner visual authority.

## 17. Motion upgrade

Current motion is materially better than the fixed-template bakeoff but still leans on pan/scale/opacity/line reveal in places.

Prefer semantic transitions that visually express causality, for example:

- document sentence -> extracted number -> chart point;
- ship -> terminal -> refinery -> storage;
- price decline -> importer/producers consequences separating spatially;
- source evidence -> analytical inference with a visible boundary.

Motion exists to explain or guide attention, not merely keep pixels moving.

## 18. Text-density doctrine

Abundant analytical content must not become abundant on-screen paragraphs.

Preferred rule:

**Narration carries nuance. Screen carries the visual thesis.**

Typical scene target:

- one headline;
- one primary visual;
- one critical label/data anchor;
- source/provenance.

Additional analytical depth should normally come from additional evidence and meaningful visual states rather than more body copy.
