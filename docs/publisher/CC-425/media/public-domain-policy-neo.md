In order to avoid further crowding of [Category:PD US Government](https://commons.wikimedia.org/wiki/Category:PD_US_Government) (as of 2019), this template should not be used if the department or part of the federal government which produced the work is known. Instead the template corresponding to the department in [Category:PD-USGov license tags](https://commons.wikimedia.org/wiki/Category:PD-USGov_license_tags) should be used.

As of 2022, please use [{{PD-USGov-Unincorporated}}](https://commons.wikimedia.org/wiki/Template:PD-USGov-Unincorporated) for the US Virgin Islands and Guam ("unincorporated territories").

  

The template automatically sets the following categories: [PD US Government](https://commons.wikimedia.org/wiki/Category:PD_US_Government)

 

## Usage

  

{{PD-USGov}}

  

The template takes no parameters.

 

### Additional information

 

The template is intended to be used in the following namespaces: the File namespace

The template is intended to be used by the following user groups: [all users](https://commons.wikimedia.org/wiki/Special:MyLanguage/Commons:Users)

Placement: In the "Permission" parameter of the [{{Information}}](https://commons.wikimedia.org/wiki/Template:Information) template (or the respective parameter of similar templates) or in the "Licensing" section

To add your language to the list of languages supported by this template, please copy the code of [Template:PD-USGov/en](https://commons.wikimedia.org/wiki/Template:PD-USGov/en) (or any other language version you prefer to translate) and replace the text strings in there (the form below can be used to create a translation, the English version is preloaded in the edit box). Please change the parameter `lang` from `en` (or whatever language you are translating) to the [language code](https://en.wikipedia.org/wiki/ISO_639-1) of your language.
