## Copied-store replay

`scripts/replay_cc041_native_window.py` works only under the current backlog checkout's
`tests/evidence/cc-041/private-replay/`. `prepare` uses SQLite's read-only online backup of
the existing ContentOps store, reuses its latest whole frozen pool and sets SHADOW_ONLY
on **the copy only**. It never changes Main, the live ContentOps store or a grant. Repeated
preparation checks the same binding instead of starting over.

```powershell
python scripts/replay_cc041_native_window.py prepare --root tests/evidence/cc-041/private-replay
python scripts/replay_cc041_native_window.py filter --root tests/evidence/cc-041/private-replay
```

The parent executes the emitted native role call(s), collects the actual result in its
own operation and uses `submit --stage <exact-stage> --response <actual-response.json>`.
It then resumes `filter` until remaining_unprocessed is zero, followed by `advance`.
The replay preserves the frozen cutoff and exact source records; retained reports and
admitted research resolve through existing evidence adapters. No later source fetch is
backdated into the replay. An uncached source is explicitly blocked, never manufactured.

Raw social captures, model response text and the copied database remain private and
Git-ignored. A sanitized acceptance summary links their exact local evidence. No external
publication, public object identity or live operation is implied by copied-store output.
All pre-existing native goals, user apps and installed automations remain untouched.
