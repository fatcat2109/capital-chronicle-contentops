# CC-047 — sources and weekly news coverage

New production bindings from 31 October 2026 select a shared twenty-request,
non-chargeable source cap. The dated ten-request policy remains valid for issued
bindings; old six-request operations keep their original budget. Acquisition and
preparation use the same budget and source owners. This branch changes no operating
root, runtime, pause, calendar or publication authority.

The existing source adapter now accepts agency-authored Fed press releases beyond
monetary releases, CFTC press releases and COT pages, BLS TED pages and EIA STEO pages.
Existing SEC filing-facts and issuer-source routes remain available alongside news.
Every admitted item still requires exact retained source and policy bytes, verified
authorship, clock and hash checks. Photos, logos, exhibits and third-party expression
gain no rights. The added hostname/path support is not admission or a rights grant.

`scripts/export_contentops_weekly_coverage.py` produces the weekly digest section from
one read-only SQLite snapshot of the existing store. It reports seven production days:
confirmed independent news articles, Main-derived articles, unclassified canonicals,
distinct Luna-filtered input records and source-walk success. Source walks count one
completed work-item/candidate, including recovery, rather than counting HTTP requests.
A lawful zero-GET source route can succeed. No denominator produces UNAVAILABLE.
Unknown actual Luna configuration is excluded and named; no missing value becomes zero.
Publication, native-return and source-stage clocks stay separate.

```powershell
python -B scripts/export_contentops_weekly_coverage.py --store "A:/Capital Chronicle/Runtime/ContentOps/contentops_daily_app_v1.sqlite3" --week-ending 2026-10-30 --output-dir tests/evidence/cc-047
```

The generated `tests/evidence/cc-047/coverage.md` is the digest section for Claude Ops
to consume after integrating this branch. `coverage.json` is the matching aggregate
input. The 30 October export is a real read-only projection, not a new acquisition,
model call, publication, schedule, integration or claim of a healthy output day.
Existing legacy model-metadata gaps remain explicit. Synthetic tests prove route and
permission enforcement, never real rights or editorial approval for their fixtures.

Validation: 70 coverage/policy/source/resolver tests and 24 canonical report-workspace
regressions passed. The real-store digest records six completed source walks, three
successful, zero counted canonical news articles and four unverified Luna-return gaps.
