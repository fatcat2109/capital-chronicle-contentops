## Consumer behavior

- A `desk_record_exports` entry in the existing feed pointer names an exact local export path and SHA256. A fixture additionally requires `allow_fixture_private_preview: true`. The production producer locator is not invented here.
- Before the imported `project(doc, {"public"})`, code checks the closed v1 schema, duplicate keys/nonfinite numbers, integrity, references, clocks and public text. An invalid export keeps its exact typed cause in the feed gap; other valid sources retain their ordinary path.
- Evidence carries exact `export_id#record_id/...` field citations, values, display precision, units, source identities and export/projection hashes. It proves retained Main report content, not fresh independent event confirmation. Joining a selected event to dossiers requires explicit event identity; chart context requires the same retained official source. The source pack stays bounded and consumes zero new acquisitions.
- Articles must retain exact used-field citations and numeric display, mandatory source attribution/disclaimers, the fixture notice when applicable, and the analysis/not-financial-advice notice. Private consensus, consensus-derived values, GEX, plans and DEMO fields never enter through a public projection.
- Charts use only exported `data_series`. The existing chart owner validates series identity/code/window/captures, exact observation/period/unit/precision and visible source/window labels. Event-card measures are not silently promoted to chart series.
- Existing outbox rows and the review table supply asset/event story memory. Reviewed unpublished articles remain unpublished. A change to an exact public record creates follow-up work; an unrelated export change does not. A later full public snapshot removes withdrawn records from current story input while retaining history.
- The Oct30 photo-less route now covers an actual MAX-approved narrow desk-record NEWS brief in DATA_OR_DOCUMENT_LENS, with exact citations, preserved mode and a substantive reason. It does not admit substantial analysis under that exception. Instagram retains its explicit skip.
- Fixtures are blocked both in native publication preparation/continuation and at the sole coordinator before registration, recovery or transport. This item makes no public send.

The consumer reuses MainReportFeed, the existing Simple/native evidence seam, story projection, ContentOpsDurableStore, native request/return owner, compiler and DurablePublicationCoordinator. There is no second source ledger, analyzer, scheduler, store owner or publisher.
