# Current Automation-First North Star

Capital Chronicle ContentOps final product is an AI-native automated content production and supervised distribution operating system.

## Target Loop

```text
Jim idea / source / artifact
-> grounded research packet
-> canonical article
-> SEO/editorial checks
-> platform-native variants
-> frozen preview hashes
-> Jim approval
-> supervised dispatch or one-step assist
-> redacted audit and metrics
-> feedback backlog
-> next content cycle
```

## Automation Hierarchy

1. Maximum automation before approval.
2. Jim remains final authority.
3. Supervised dispatch at live edge.
4. API/webhook where safe, scoped, and auditable.
5. One-step CDP/operator assist where platform automation is paid, blocked, brittle, or not worth integration.
6. Manual fallback only for recovery, proof, or hard platform limits.

## Dispatch Tier Model

| Tier | Meaning | Use |
|---|---|---|
| Tier 1 | Supervised API/webhook | Safe official automation with scoped approval. |
| Tier 2 | One-step CDP/operator assist | Prepared payload; Jim performs final native click. |
| Tier 3 | Manual fallback package | Exact export packet plus operator-supplied proof. |

Mixed tiers can still satisfy final product. Every platform does not need Tier 1.

## Current Safety Posture

Current repo state remains fail-closed unless status docs and committed packets prove readiness.

Fixture/manual/operator-supplied evidence is not live/API/provider evidence.

No final-product claim is valid until committed tests, packets, and UI visibility back it.
