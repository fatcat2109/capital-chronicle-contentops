## Review Rules

- Human review is always required.
- Research missing evidence is preserved.
- Article limitations and disclosure are required.
- SEO must preserve limitations and caveats.
- Discord drop candidates require discussion question and disclosure.
- Platform variants are review-only and never dispatch-ready.
- X remains manual.
- LinkedIn org and TikTok remain deferred if included.

## Prohibited Content

No personal financial guidance, alert-service framing, trade instructions, entry/exit framing, target levels, position sizing, guaranteed predictions, fake citations, fake metrics, fake public links, endpoint values, webhook values, or secrets.
